Welcome to the Java documentation of the Keypop Card Java API, part of the Keypop open-source project hosted by the Eclipse Foundation.

Aligned with version 3.0 of the Terminal Card API specification issued by the Calypso Networks Association (available here), which carries the normative contract of each type and operation documented below, it is the link between the layer dedicated to the functional processing of cards and the layer of communication with the card readers. It defines the interfaces needed to communicate with the cards and manage the selection mechanisms.
